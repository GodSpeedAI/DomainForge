# Prove Gates

## Overview
The `just prove` self-proving harness: each script establishes one claim from
`PROOFS.md` by running the real CLI, then writes a JSON evidence fragment to
`evidence/latest/fragments/`. `collect-evidence.sh` runs last and merges the
fragments into the published evidence pack.

## Interface
- `[language.sh:POSITIVE_FIXTURES]` — parses and validates seven positive
  fixtures, requires `validate` to reject every `*.sea` under
  `fixtures/projection_cell/invalid` (at least 3 of them), and proves
  format stability on `fixtures/projection_cell/format_stable.sea`; writes
  `language.json`.
- `[canonical.sh:CARGO_RUN]` — projects the projection-cell fixture to
  `--format rdf` in two isolated dirs at a pinned `--created-at`, byte-compares the
  outputs, and asserts `pack build` `source_graph_hash` + `meaning_fingerprint`
  are stable across independent rebuilds; writes `canonical.json`.
- `[check-contracts.sh:GATE_DIR]` — projection-contract parity check between
  `scripts/verify/projection-targets/*.sh` and
  `scripts/verify/projection-targets/contracts/*.yaml`; writes `contracts.json`.
- `[projections.sh:bash scripts/verify/projection-targets/all.sh]` — runs the
  authoritative all-target gate unchanged, then derives a per-target
  `projection_gates` object from the contract files; writes `projections.json`.
- `[roundtrip.sh:roundtrip-cell.sh]` — re-runs the authoritative CALM round-trip
  gate, then proves a KG round-trip (`project --format kg` → `import --format kg`)
  by comparing entity/resource/flow counts; writes `roundtrip.json`.
- `[drift.sh:build]` — proves `pack diff` reports an empty typed diff for two
  independent rebuilds of the same source and a non-empty `breaking` diff after
  renaming entity `Approver` → `Reviewer`; writes `drift.json`.
- `[collect-evidence.sh:REQUIRED]` — merges `evidence/latest/fragments/*.json`
  into `evidence/latest/proof.json`, renders `evidence/latest/proof.md`, and
  parses claim statuses out of `PROOFS.md`.

## Invariants
- `[collect-evidence.sh:REQUIRED]` — the six fragments `language`, `canonical`,
  `projections`, `roundtrip`, `drift`, and `contracts` must all exist before the
  merge; a missing fragment aborts the run.
- `[collect-evidence.sh:overall]` — `overall_result` is `passed` only if
  `.language.passed`, `.canonical_determinism.passed`, `.drift.passed`,
  `.contracts.passed`, `.roundtrip.calm.passed`, `.roundtrip.kg.passed`, and every
  `.projection_gates[].passed` are true.
- `[check-contracts.sh:gate_optional]` — a contract without a matching gate script
  must declare `gate_optional: true`; a gate script without a contract is always a
  parity failure.
- `[check-contracts.sh:target/status/preserves/prohibited_losses/native]` — every
  contract must declare all five fields.
- `[language.sh:shopt -s nullglob]` — fewer than 3 negative fixtures is a failure,
  so the fixture set cannot silently shrink to nothing.
- `[language.sh:STABLE]` — format idempotence is proven only on the round-trip-clean
  subset `format_stable.sea`; the Relation/Policy/Metric formatter gap is a
  documented partial in `PROOFS.md` CLAIM-FORMAT-STABILITY rather than a hidden
  failure.
- `[canonical.sh:sed '/^# Generated by DomainForge/d']` — the source-path
  provenance comment is the one documented exclusion from the byte comparison; all
  semantic triples are compared byte-for-byte.
- `[drift.sh:pack diff ... || true]` — `pack diff` exits nonzero on breaking
  changes by design, so the script asserts on JSON content rather than exit status.
- `[projections.sh:tla_native]` — the `tla` native flag reflects whether Java and
  `tla2tools.jar` were actually present, not merely whether the gate ran.
- `[collect-evidence.sh:command -v jq]` — `jq` is a hard requirement; the script
  exits if it is absent.

## Side Effects
- `[canonical.sh:FRAG_DIR]` (`check-contracts.sh`, `collect-evidence.sh`,
  `drift.sh`, `language.sh`, `projections.sh`, `roundtrip.sh`) — creates
  `evidence/latest/fragments/` with `mkdir -p`.
- `[collect-evidence.sh:PROOF_JSON]` — writes `evidence/latest/proof.json` and
  `evidence/latest/proof.md`, overwriting prior evidence.
- `[canonical.sh:RUN1]` (`drift.sh:WORK`, `language.sh:WORK`,
  `roundtrip.sh:WORK`) — creates `mktemp -d` work directories removed by
  `trap ... EXIT`.
- `[canonical.sh:pack build]` — writes `pack.json` artifacts into the temp dirs
  and runs a full `cargo run` build.
- `[roundtrip.sh:project --format kg]` — writes a `model.ttl` Turtle file into the
  temp work dir and re-imports it.
- `[drift.sh:sed -i]` — mutates a copied fixture (`$WORK/b.sea`) in place to
  introduce the declared drift.
- `[projections.sh:all.sh]` — transitively executes every projection gate,
  including the external `opa` and `openshell-prover` invocations.

## Verification
- Run: `just prove`
- Run (single gate): `bash scripts/prove/language.sh`
- Run (evidence merge only): `bash scripts/prove/collect-evidence.sh`
