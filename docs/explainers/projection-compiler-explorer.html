Deterministic ID Minting (projection::ids)

Element IDs and QNames are minted via xxh64 seed 42 joining the family tag and constituent tokens with U+0001 (\u{1}) field delimiters.

ArtifactSink Path Containment Sandbox

Every projection file write passes through protobuf::validate_output_path(). Path traversal attempts are trapped and aborted before filesystem access.
